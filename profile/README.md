# MeetMage Extensions

Free, production-ready Magento 2 & Hyvä Theme extensions by [Meet Shekhat](https://meetshekhat.com).

## Why MeetMage?

- **100% free & open source**: MIT licensed, no premium upsells
- **Hyvä compatible**: built for Hyvä's Alpine.js + Tailwind CSS architecture, with Luma support
- **AI-powered features**: AI for SEO, search and store automation
- **Performance first**: no bloat, optimised queries, lazy loading
- **9+ years of Magento expertise**: by Meet Shekhat, Senior Adobe Commerce developer

## Quick install

```bash
composer require meetmage/module-<name>
bin/magento module:enable MeetMage_<ModuleName>
bin/magento setup:upgrade
```
